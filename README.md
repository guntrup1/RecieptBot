# ReceiptBot 🧾

Telegram бот для учёта совместных расходов на еду. Принимает фото чеков, анализирует их через Gemini AI, принимает голосовые пояснения и публикует структурированные отчёты в Telegram-канал.

---

## Возможности

- 📸 **Анализ чеков** — загрузите фото, Gemini OCR распознает магазин, дату и все позиции
- 🎤 **Голосовые пояснения** — расскажите кто что купил лично, бот разберёт сам
- 📊 **Автоотчёт** — форматированный отчёт с остатком бюджета отправляется в Telegram-канал
- 📋 **История чеков** — все чеки за текущий месяц
- 💰 **Бюджет на месяц** — установка и отслеживание бюджета

## Установка

### 1. Требования
- Python 3.11+

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка `.env`
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GEMINI_API_KEY=ваш_ключ_gemini
TELEGRAM_CHANNEL_ID=@ваш_канал  # или -100xxxxxxxxx для приватного
PERSON_1_NAME=Жора
PERSON_2_NAME=Настя
CURRENCY=€
GEMINI_MODEL=gemini-2.0-flash-lite
```

> ⚠️ **Важно:** Бот должен быть **администратором** вашего Telegram-канала!

### 4. Добавить бота в канал
1. Откройте ваш канал → Управление каналом → Администраторы
2. Добавьте бота как администратора с правом **публикации сообщений**

### 5. Узнать ID канала (если приватный)
- Перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)
- ID будет вида `-100xxxxxxxxx`

## Формат отчёта

```
📅 Дата: 28.08.2026
🏪 Магазин: Lidl
💸 В сумме потрачено: 45.50 €
💰 Осталось: 354.50 €

📝 Детали:
  • Молоко 1л × 2 — 2.89 €
  • Хлеб — 1.35 €
  • Чипсы Lay's — 2.75 €
  • Яблоки — 3.62 €

🔄 Вернуть в бюджет:
  — Жора: 2.75 € (за чипсы)
  — Настя: 3.62 € (за яблоки)
```

## Голосовые пояснения — примеры

> "Жора взял чипсы за 2.75, Настя яблоки за 3.62"

> "Из этого чека Жора брал пиво за 4 евро, остальное общее"

> "Я взял шоколадку за 1.5, Настя йогурт за 2 евро"
